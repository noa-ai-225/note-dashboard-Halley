# ハリーのnote実験記録 — 時間別観測＆バックアップラボ

**「一緒に試して、noteを育てよう」** 🌱🦔

毎日 **9時 / 14時 / 20時 / 23時** の4回、あなたの note ダッシュボードから次の5つの数字を自動で記録し、**「前の時間帯からどれくらい増えたか（増減）」**を画面とExcel用CSVにまとめるツールです。

- 👀 **インプレッション**
- 📖 **ページビュー（PV）**
- ❤️ **スキ数**
- 💬 **コメント数**
- 🦔 **フォロワー数**

**プログラミングの知識は一切不要です。**  
最初の設定だけパソコンで行えば、あとは**スマホやiPadのブラウザからいつでも確認・操作**できます！

---

## かんたん導入手順（Windowsパソコン・所要時間 約5分）

### ステップ1：パソコンに「Python」を入れる（すでに入っていれば飛ばしてOK）

1. [Python公式ダウンロードページ](https://www.python.org/downloads/) を開きます。
2. ページ上部にある黄色の **「Download Python 3.xx.x」** ボタンを押してダウンロードします。
3. ダウンロードしたファイルを開き、**最初の画面の一番下にある**  
   ☑️ **「Add python.exe to PATH」に必ずチェックを入れてください！**
4. そのまま真ん中の **「Install Now」** を押して完了するまで待ちます。

---

### ステップ2：このツールをダウンロードして解凍する

1. このページの右上（緑色のボタン）**「`<> Code`」** をクリックし、一番下の **「Download ZIP」** をクリックします。
2. ダウンロードフォルダに入った `note-dashboard-Halley-main.zip` を**右クリック**して **「すべて展開」** を選び、わかりやすい場所（デスクトップやドキュメントなど）にフォルダを出します。

---

### ステップ3：初期セットアップ（ダブルクリック1回）

1. 解凍したフォルダの中にある **`scripts`** フォルダを開きます。
2. **`setup_windows.bat`** をダブルクリックします。
   - ※ もし「WindowsによってPCが保護されました」という青い画面が出たら、**「詳細情報」→「実行」** を押してください。
3. 黒い画面が開き、必要な部品のダウンロードが自動で進みます（1〜2分ほど）。  
   **「セットアップがすべて完了しました！」** と表示されたら、何かキーを押して画面を閉じます。

---

### ステップ4：アプリを起動して、noteに1回だけログインする

1. フォルダの一番上（`scripts` の1つ外）に戻り、**`run_ui_lan.bat`** をダブルクリックします。
   - ※ 「Windowsセキュリティの重要な警告（ファイアウォール）」が出たら、スマホから繋ぐために **「アクセスを許可する」** を押してください（プライベートネットワークにチェック）。
2. パソコンのブラウザが自動で開き、**「ハリーのnote実験記録」** 画面が表示されます。
3. 右側の「**初回ログイン認証**」から、あなたの note にログインします：
   - **方法1（おすすめ）**: **「PC画面にブラウザを開く」** ボタンを押す → 開いたChromeで普段通り note にログインする（ダッシュボードが開くと自動で保存されて閉じます）。
   - **もしGoogleログインで「安全でない可能性」等のエラーが出たら → 方法2（Cookie貼り付け）**:
     1. 普段使っているChromeでログイン済みの `https://note.com` を開く
     2. キーボードの **`F12`** キーを押す
     3. 上のタブから **`Application`（または `アプリケーション`）** → 左メニュー **`Cookies`** → **`https://note.com`** を開く
     4. 名前に **`_note_session_v5`**（なければ `_note_session`）と書かれた行を探し、右側の **Value（値）** をコピーして、本アプリの「方法2」の枠に貼り付けて **「取り込んで接続確認」** を押します。

---

### ステップ5：スマホ／iPadから使えるようにする（1クリック）

1. ログインできたら、左側の **「今すぐ観測を実行」** ボタンを押してみます。数秒であなたの最新データとフォロワー数が表示されます！
2. すぐ下にあるオレンジ色のボタン **「PC起動時に自動起動を登録（おすすめ）」** をクリックします。  
   → これにより、次からパソコンを立ち上げた時に裏側で自動起動するようになり、黒い画面を開き直す必要がなくなります。
3. 同じ場所に出ている **「スマホ・iPadから開くURL」**（例：`http://192.168.x.x:8766/`）を、**自宅の同じWi-Fiにつないだスマホ／iPadのSafariやChrome** で開きます。
4. スマホで「ホーム画面に追加」しておけば、あとはいつでもスマホだけで **9時／14時／20時／23時の記録と増減確認・CSVダウンロード** ができます！

## よくある質問・困ったときは（FAQ）

- **Q. スマホから開けません（「アクセスできません」と出る）**
  - パソコンとスマホが**同じ自宅Wi-Fi**につながっているか確認してください（スマホが4G/5G回線だと開けません）。
  - パソコンがスリープ中、または電源オフの時は開きません。
  - 最初の起動時にWindowsファイアウォールの警告で「キャンセル」を押してしまった場合は、パソコンのWindowsセキュリティ設定からPythonの通信を許可してください。
- **Q. いきなり「期限切れ・再ログインしてください」と出た**
  - note側のログイン有効期限が切れると（数週間〜数ヶ月ごと）、PC側で再度「方法1」または「方法2」からログインし直す必要があります。
- **Q. 取得する時間帯を変えたい**
  - スマホ画面の「観測時刻（カンマ区切り）」欄で `09:00, 14:00, 20:00, 23:00` を書き換えて「時刻設定を保存」を押すだけで変更できます（noteへの負荷防止のため、最短2時間以上あけてください）。
- **Q. Excelで数字を開きたい**
  - 画面上部の「**時間別CSV保存**」または「**記事CSV保存**」を押すと、Excelで文字化けせずに開けるCSVファイルがそのままスマホ・PCに保存されます。

### 1. macOS / Linux でのコマンド導入
```bash
git clone https://github.com/noa-ai-225/note-dashboard-Halley.git
cd note-dashboard-Halley
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
python src/ui_server.py --lan
```

### 2. PC電源オフでも動く完全クラウド運用（GitHub Actions）
1. このリポジトリを **Private（非公開）リポジトリ** として複製します（※Publicリポジトリでは個人情報保護のため自動コミットが停止します）。
2. PCで初回ログイン後、管理UIの「上級者向け設定」内にある「`NOTE_SESSION_STATE_B64` を生成」（または `python src/export_secret.py`）で文字列をコピーし、GitHubリポジトリの **Settings → Secrets and variables → Actions** へ登録します。
3. `.github/workflows/scheduled_backup.yml` により毎日 JST **09:00 / 14:00 / 20:00 / 23:00** に自動実行され、`data/exports/note_hourly_history.csv` と `note_articles_latest.csv` をGitHubスマホアプリから閲覧できます。

### 3. セキュリティについて
- 認証情報（`data/auth/`）や記録データ（`data/note_stats.db`, `data/exports/*.csv`）はすべてあなたのパソコン内のみに保存され、外部へ送信されません。
